# Contracts

The WIT contracts moved to the system repository (`dodos`, folder `contracts/`) on 14 November 2026: `core.wit`, `store.wit`, `ui.wit`, `actions.wit`, `catalog.wit`. They are code: that repository's `verify` command checks them.

The kernel interface in code is the `abi` crate of the kernel repository (`dodos-kernel`); its description is [architecture/kernel-interface.md](../architecture/kernel-interface.md).
