# Drafts

Working drafts written by agents, kept here so that they are not lost. They are **not** the contract: the contract is [kernel-interface.md](../../architecture/kernel-interface.md), and a rule exists only once it is written there and recorded in the [decision log](../../decisions/README.md).

Superseded since where `irq-tasks-startup.md` gives memory to nodes in equal shares and every device to the boot node (rejected or replaced by D-112 and D-113; chunks and devices that follow their driver, from `nodes-memory-devices.md`) |
| `nodes-memory-devices.md` | Integrated on 16 November 2026: chunks, floors, ownership words, `memory_take`, `memory_give`, `memory_split`, the device table, devices that follow their driver ([Memory and devices between nodes](../../architecture/kernel-interface.md#memory-and-devices-between-nodes)). | `ownership-alternatives.md` | Integrated on 16 November 2026: the living part of the machine table is read-only in every kernel and written only through the write gate (D-115) ([The write gate](../../architecture/kernel-interface.md#the-write-gate)) |
